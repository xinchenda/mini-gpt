## 先备数据，再开 GPU

新候选为宽度 512、12 层、8 头、上下文 512、16384 BPE，约 46M 参数。该方案尚未接受 CUDA 验证，也未训练完成。使用 FineWeb-Edu 一个固定版本的分片，先在本机下载、去除精确重复、按文本内容散列划分 train/validation/test，训练独立 tokenizer，再生成 uint16 文件。数据准备不消耗云 GPU 费用。先做 300M 训练 token 上限的准备，正式训练量由测速决定，不预先宣称一定能完成。

数据读取改为内存映射，避免把几亿 token 转成 Python 列表。EOS 分隔文档，窗口允许越过 EOS；这一策略与本机文学语料的文档内采样不同，必须在报告中披露。公开任务污染和近似重复尚未检查，完成前不能声称无污染。

`--max-seconds` 只负责保存训练断点并退出，不能停止实例收费。`scripts/budget_run.py` 在 AutoDL Linux 上运行一个有时限的阶段，成功或失败后调用官方关机命令；默认仅打印计划，显式执行才会关机。它不能覆盖脚本启动前的收费时间，平台定时关机和账单复核仍需配置。

[AutoDL 官方省钱说明](https://www.autodl.com/docs/save_money/)说明了无卡模式和程序结束后关机；[数据盘计费说明](https://www.autodl.com/docs/local_disk/)说明付费扩容关机后仍可收费。本轮不启用付费扩容。
