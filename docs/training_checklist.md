# 大模型训练工程检查表

## 结论

当前项目是方向正确的小规模 Transformer 预训练实验。它包含假设、单变量对照、固定验证集、实验记录和 checkpoint，并非随意堆叠参数。它仍不是完整的大模型预训练系统。

## 专业流程与当前状态

| 阶段 | 专业做法 | 当前状态 |
|---|---|---|
| 目标和预算 | 明确能力目标、参数量、token 预算、算力和停止条件 | 部分完成，模型规模仍属于教学级 |
| 数据授权 | 记录许可证、来源和版本 | 已完成公版书来源记录 |
| 数据处理 | 去重、质量过滤、乱码清理、个人信息和污染检查 | 已提取正文并校验书号、SHA256、整书与长段落重复。近似重复和更广泛质量筛选待做 |
| 数据角色 | 训练、开发验证、最终测试严格隔离 | 已完成 manifest，但早期实验重复使用过测试书 |
| Tokenizer | 训练子词词表，检查压缩率和无损解码 | 已完成 BPE 与多版本 tokenizer |
| 模型实现 | Attention、规范化、残差、初始化和小规模过拟合测试 | 已完成基础实现与多种单变量实验 |
| 优化 | warmup、学习率调度、梯度裁剪、吞吐和内存记录 | 已完成对照实验 |
| Checkpoint | 模型、优化器、学习率进度、随机采样和恢复验证 | 已完成模型与 AdamW 状态、采样状态保存和续训测试 |
| 评估 | 固定验证、独立测试、多指标和生成质量 | 已有固定窗口和全书交叉熵、留出书续写排序与生成样例，通用能力评测待做 |
| 可复现性 | 配置、代码、数据、日志、随机源和环境版本 | 已有 manifest、CSV、元数据和固定种子 |
| 多种子评估 | 使用配对种子估计初始化与采样波动 | 已完成宽度 64/128 的三组配对种子 |
| 分布式训练 | 数据并行、模型并行、梯度累积和容错 | 尚未实现 |
| 后训练 | 指令微调、偏好优化和任务评估 | 尚未开始 |

## 当前最重要的缺口

1. 数据审计目前覆盖完整长段落的精确匹配。增加语料类型前需要补近重复、文本质量与许可审查。
2. 参数量和 token 量仍远低于常规大模型预训练规模。
3. 续写排序聚焦局部顺序，真实任务需要各自的验证样本和指标。
4. 单机单卡 MLX 训练没有分布式通信、故障恢复和长时间运行验证。
5. 已使用三个种子，但小差异仍需更多种子和置信区间。
