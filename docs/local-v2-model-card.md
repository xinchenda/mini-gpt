# MiniGPT 本机 v2 模型卡

## 模型与任务

英文自回归文本模型，从随机权重在文学语料上训练，再进行格式修正、上下文迁移和百科语料扩展。最终本机版本有 5,066,752 个参数，6 层、宽度 256、8 个注意力头、256 token 上下文和 1,024 项 Byte-Level BPE。输入输出嵌入共享，使用学习式位置嵌入、Pre-LayerNorm、GELU 和因果 SDPA。

模型包：`artifacts/v2`。工程入口：`minigpt_v2`。本卡不包含尚未完成的云端候选结果。

## 训练资料

27 本 Project Gutenberg 文学作品经段落格式清洗后，与官方 WikiText-2 训练切分混合。最终混合训练语料共有 10,791,659 token、28 个文档。验证使用独立 Wind 与 WikiText 验证切分；测试文件不用于梯度更新。

全部阶段、语料来源、处理规则、验证选择和恢复命令见 [训练记录](TRAINING_GUIDE.md)。本机执行 11 组正式实验，总计 115,000 次更新、117,760,000 个训练目标。最终最佳权重的初始化链实际经过 39,000 次更新；不能把全部候选的总计算量当作该权重自身的训练量。

## 适用范围和限制

适用于教学、训练工程复现、缓存正确性验证和英文短文本生成实验。输出可能重复、不连贯或与事实不符，不具备可靠的指令遵循能力。公开任务成绩很弱，不适用于通用问答、金融、医疗、法律或其他依赖事实准确性的应用。

只进行了有限随机种子重复；部分对照同时改变结构、数据或上下文。HTTP 实现提供本机接口与边界检查，未验证对外生产部署的认证、安全隔离、持续可用性和负载容量。

## 加载与完整性

使用 `python -m minigpt_v2.inference artifacts/v2 --prompt "The old man"`。包内 `sha256.json` 校验权重、词表、配置和来源记录。推理权重不包含优化器状态；完整训练状态保留在本机实验目录。
